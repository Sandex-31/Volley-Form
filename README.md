# Volley-Form

**Wapatanka Volley Tool**: a web app for the Wapatanka volleyball team. Exercise feedback forms, training plans, players, matches and video analysis.

It's plain HTML/CSS/JavaScript (no build step) with Firebase Realtime Database.

## Developing

Want to work on the site from your computer? Start here. Local development uses a Firebase emulator, so you can't break the real data.
